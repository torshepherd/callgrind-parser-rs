## Scope of agreement

The Rust exporter uses the production decoder, then checked u128 aggregation.
The KCachegrind adapter disables synthetic cycle-node presentation for the
ordinary comparison and selects each part independently. Both export:

| Row | Compared quantity |
| --- | --- |
| P | Part index and event names |
| T | Exclusive part totals |
| F | Function identity and exclusive event costs |
| E | Caller/callee identities, summed call counts and inclusive edge costs |
| L | Function, attribution file, source line and exclusive event costs |

Names are hex-encoded UTF-8 in a TSV adapter format, avoiding delimiter
ambiguity. The comparison aligns event vectors by event name and normalizes
zero-only materialized rows. At this test boundary only, absent names and
literal `???` are normalized to KCachegrind's empty-name convention.

This is not annotation text parity, arbitrary-input identity equivalence,
inclusive-function/cycle-policy parity, exact jump parity, disassembly
attribution, or pprof validation. Call-target positions are retained by Rust
but not compared here because KCachegrind discards them. KCachegrind's line view
suppresses some jumps, so those need separately scoped tests.

## Native environment

Nix was absent. These were native runs of the checked-in matrix with pinned
source versions, **not** a rerun of the hermetic flake closure. SQLite build
flags and host libraries differ from the prior Nix environment.

- SQLite 3.51.2:
  [amalgamation archive](https://www.sqlite.org/2026/sqlite-amalgamation-3510200.zip),
  SHA-256 `6e2a845a493026bdbad0618b2b5a0cf48584faab47384480ed9f592d912f23ec`.
  Compiled shell.c + sqlite3.c using `cc -static -O2 -g`,
  `SQLITE_THREADSAFE=1`, `SQLITE_ENABLE_COLUMN_METADATA`,
  `SQLITE_ENABLE_FTS5`, `SQLITE_ENABLE_RTREE`, and `-lm -ldl -lpthread`.
- Valgrind 3.26.0: the source/build pinned in SOURCE-AUDIT.md.
- KCachegrind: the pinned Git checkout above, built directly from libcore's
  16 .cpp files with C++17 and Qt6Core, without GUI dependencies.
- Qt 6.4.2, Ubuntu package version `6.4.2+dfsg-21.1build5`. Public packages
  were extracted into scratch rather than installed system-wide.
  qt6-base-dev SHA-256:
  `f81ea0070597621c2a1027d753c343c8204a2fce601b1a92d6e264d909a32bfb`;
  libqt6core6t64 SHA-256:
  `1f6e26589271c1d7aa549cb86d0156ff589b764d37edf356712fecebfe5f30f8`.
  libb2-1 and libdouble-conversion3 were also extracted; runtime used
  LD_LIBRARY_PATH pointing at the extracted library directory.

Papercuts: system apt failed while attempting setgroups/seteuid in the managed
container. Do not bypass that with privilege escalation. Local public-package
extraction sufficed. The profiled sqlite3 must be the actual binary or a
symlink to it: a shell wrapper execs another image, which the default Valgrind
invocation did not follow, leaving an empty profile. The wrapper was replaced
by a symlink before the successful matrix. The reference Perl annotator emitted
uninitialized-value warnings at line 1285 during full-simulation source
annotation; these were not suppressed or counted as evidence of output parity.
